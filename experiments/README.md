# Эксперименты

В `notebooks/` храним ноутбуки Jupyter (`.ipynb`) для анализа данных и сравнения моделей.

Ноутбук задаёт эксперимент и показывает результаты. Когда подготовка признаков или расчёт метрик становятся общими для нескольких экспериментов, выносим их в `src/ozon_demand_service/` и импортируем установленный пакет.

Для сравнения моделей фиксируем версию данных, даты обучения и оценки, горизонт прогноза и параметры. Когда появятся повторяемые запуски с разными наборами параметров, их конфиги можно вынести в `experiments/configs/`.

С первым ноутбуком добавим сервис Jupyter в профиле `dev`. Его образ будет устанавливать пакет приложения и группу `notebooks` из `uv.lock`. Каталог `notebooks/` подключим отдельно, чтобы изменения ячеек сохранялись в рабочей копии. [uv и Jupyter](https://docs.astral.sh/uv/guides/integration/jupyter/)
