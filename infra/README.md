# Инфраструктура данных и машинного обучения


| Каталог                       | Роль                                                                                                                                                                           |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`python/`](python/)                 | Общая сборка Python. Из одного Dockerfile получаем образ приложения и образ с инструментами проверки.        |
| [`airflow/`](airflow/)               | Расписание импорта, обучения и расчёта планов. DAG хранит порядок шагов и вызывает общий Python-пакет. |
| [`mlflow/`](mlflow/)                 | Настройки отслеживания экспериментов и доступа к артефактам обучения.                                                 |
| [`object-storage/`](object-storage/) | Настройки будущего S3-совместимого хранилища выгрузок и файлов моделей.                                                |

Версия Airflow и её зависимости будут закреплены в собственном окружении. Корневой `uv.lock` относится к Python-приложению. В окружение исполнителя Airflow устанавливается та же сборка приложения, которую использует API.
