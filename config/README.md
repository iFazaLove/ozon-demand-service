# Настройки приложения

Точка входа FastAPI и HTTP-маршруты будут в `src/ozon_demand_service/api/`. Здесь хранятся настройки запуска приложения.

- [`backend.toml`](backend.toml) содержит публичные значения по умолчанию для будущего запуска API.

При реализации API подключаем `backend.toml` как файл только для чтения, например в `/etc/ozon/backend.toml`, и передаём этот путь через `OZON_SETTINGS_PATH`. Внутри контейнера API будет слушать `0.0.0.0:8000`, а для локального браузера Compose опубликует порт на `127.0.0.1:8000`. Адрес для браузера задаётся в [`frontend/`](../frontend/). Строка подключения к БД передаётся отдельной переменной окружения.
